Server Connection Error

Unable to connect to the application server. The server may not have started correctly.

📋 Troubleshooting Steps:

  1. Make sure MongoDB is running on your system
  2. Check that all server dependencies are installed:
    cd server && npm install
  3. Verify your .env file is configured with:
    • MongoDB connection string
    • JWT secret
    • Cloudinary credentials (if using file uploads)
  4. Check the console logs for specific error messages
  5. Try restarting the application
